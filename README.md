# NEXTEST — Frontend

Aplikasi CBT anti-contek sekolah (HTML/CSS/JS murni). Backend: Google Apps Script (REST API).

1. Isi `js/config.js` → `GAS_URL` = alamat `/exec` Web App Apps Script Anda.
2. Unggah folder ini (tempat `index.html` berada) ke GitHub → Settings → Pages → `main` / `(root)` → Enforce HTTPS.
3. Panduan lengkap: `PANDUAN-INSTALASI.md`.

Struktur: `index.html` · `css/app.css` · `js/` (core, ui, login, siswa, exam, admin, data, bank, laporan) · `img/` · `templates/` (template impor soal Word/Excel & siswa).

Tidak ada rahasia di folder ini. Satu-satunya konfigurasi adalah URL `/exec` (bukan rahasia).
